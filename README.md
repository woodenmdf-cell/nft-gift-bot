# Shar Yutar — Telegram o'yin

Bitta maydonda barcha o'yinchilar (bo'sh joylarni botlar to'ldiradi). Server faqat Python standart kutubxonasida.

## Railway sozlamalari (Variables)
- `BOT_TOKEN` — @BotFather tokeni (faqat shu yerda saqlanadi, kodga yozilmaydi)
- `ADMIN_ID` — ixtiyoriy. Bo'lmasa, botga birinchi bo'lib `/admin` yozgan odam admin bo'ladi
- Volume: `/data` ga ulang (o'yinchilar hisoblari saqlanib qolishi uchun)
- Networking → Generate Domain (o'yin manzili avtomatik olinadi)

## Qoidalar
- Har 50K token o'yinda yig'ilganda hisobga o'tadi; 500K = 50 ⭐ balansga
- ⚡ 2x tezlik: 30 s, 1K token
- 🎯 KIL: o'zing TOP-3 da bo'lsang, TOP-3 dagi boshqasiga, 10 ⭐. 🛡 ANTI-KIL: 10 ⭐, 10 soniya ichida
- Yulduz so'rovlari adminga Telegram'da keladi (✅ Yuborildi / ❌ Rad etish)
